# Changelog

All notable changes to TrackMed will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

### Added
- Initial project setup
- Medication management (add, edit, delete, pause)
- Flexible scheduling system (daily, specific days, interval, as-needed)
- Time window support (Morning, Noon, Afternoon, Evening, Night)
- Notification system with Take, Skip, Snooze actions
- Follow-up reminder notifications
- Stock tracking with low-stock alerts
- Home screen widget for quick access
- Vacation mode to pause notifications
- Backup and restore functionality
- Onboarding flow with permission requests
- Dark theme support
- Material 3 design

### Technical
- Kotlin 2.1 with KSP for annotation processing
- Jetpack Compose with Material 3
- Room database for local storage
- Hilt for dependency injection
- WorkManager for background tasks
- AlarmManager for exact timing
- Jetpack Glance for widget
